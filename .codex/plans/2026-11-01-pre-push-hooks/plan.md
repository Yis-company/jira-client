# Pre-push guard

## Decision for review

Install a small local Git pre-push hook automatically on `pnpm install`. Run the existing CI frontend and release-helper checks before a push. Keep native compilation, release packaging and PR-specific policy in CI. No task runner, remote cache, new test framework, app behavior or infrastructure changes.

## Acceptance and limits

A fresh standard clone plus successful `pnpm install` has the guard; repeated installation preserves it. Personal hooks and custom hook paths are never overwritten or silently disabled. Every selected failure and missing prerequisite blocks a local fixture push; all passing checks allow the synthetic ref update. CI retains native, changeset and release coverage. No real remote is pushed, no external product operations occur, and unrelated files remain intact. CI results, other OS behavior, and protection against deliberate bypass are not implied by local fixture results.
